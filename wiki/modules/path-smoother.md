# 路径后处理：平滑三件套

> 源码：`src/robot/planner/`（`path_smoother.hpp/cpp`，接入 `planner_core.cpp`）

## 职责

A* 输出的路径是**栅格中心点的锯齿折线**：8 邻域搜索的斜向段呈楼梯形，直接交给 Pure Pursuit 会导致转向角频繁抖动、跟踪横向误差偏大。路径后处理管线在"规划 → 控制"之间补齐工程缝隙：

```text
A* 原始路径 → ① 视线快捷化 → ② 固定弧长重采样 → ③ 三次样条平滑 → (碰撞回退) → /path
```

## ① 视线快捷化 `PathShortcutter`

贪心裁剪锯齿拐角：从锚点出发向后寻找**视线可达的最远点**，直接跳转：

- 视线检测回调（`planner_core` 内实现）：两点连线按**半格分辨率**步进采样，任一落点栅格被占据即不可达
- 效果：路径点数从"每格一点"降到"每条直线段两端一点"，长度显著缩短

## ② 固定弧长重采样 `PathResampler`

快捷化后的路径段长度不均（长直线 + 短转角），直接做样条会导致弧长参数化畸形。重采样按**固定间距线性插值**重建路径：

- 首尾点精确保留，过近的尾点去重
- 采样间距 = 地图分辨率（0.1m）

## ③ 自然三次样条平滑 `SplinePathSmoother`

以**弧长 s 为参数**，对 x(s)、y(s) 分别拟合 C² 连续的自然三次样条：

- **三对角方程组**用追赶法（Thomas 算法）O(n) 求解各节点二阶导数（自然边界条件）
- 按固定间距在样条上重采样输出，曲率连续、无锯齿

### 碰撞回退（安全优先于平滑）

样条可能把路径"切"进障碍物（拐角内侧）。平滑后**逐点做自由空间检测**，任一点落入占据栅格即触发回退：

```cpp
if (smoothed.used_collision_fallback) {
    return resampled;  // 退回快捷化路径（仍是自由的）
}
```

退化场景（点数 < 3、零长度段）均直接返回原路径，不做平滑。

## 分层设计

`path_smoother.hpp/cpp` 是**纯算法层**：不包含任何 ROS 头文件（PointPath2D 是普通 struct），可独立编译与单测；与 ROS 的耦合（PoseStamped 转换、视线/自由空间回调）全部留在 `planner_core`。

## 参数

采样间距与碰撞检测步长均由 `map_.info.resolution` 推导，无新增可调参数。
